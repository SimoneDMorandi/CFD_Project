Questa cartella è già pronta per l'uso con il Microsoft Developer Studio ed il compilatore Fortran Intel.
Il file da cliccare è Euler_1D_v3.0.vfproj.
Se non lavorate in ambiente Miscrosoft developer studio, basta compilare tutti i files con estensione .f e linkarli insieme.
La soluzione numerica si trova nel file num_sol.dat, metre quella teorica viene scritta nel file theo_sol.dat.
